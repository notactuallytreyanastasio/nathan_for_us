Framecut Grabber is a little desktop app. Paste any YouTube (or yt-dlp-supported) link, and it downloads the video, slices it into 1-per-second frames on your machine, and sends the frames + captions to your Framecut server — where you pick a range and render a GIF. No terminal. No install. yt-dlp and ffmpeg are built right in.

Setup — about a minute

1

Download the app for your OS

It's a single ~100 MB download because a full copy of yt-dlp and ffmpeg is bundled inside — nothing else to install.

2

Open it

macOS
Windows
Linux

Unzip and (optionally) drag Framecut Grabber to Applications. The app isn't signed with an Apple certificate, so the first time, right-click it → Open → Open. After that it launches normally.

Double-click the .exe. Windows SmartScreen may warn on first run — click More info → Run anyway.

Make it executable and launch it (needs a desktop with OpenGL):

chmod +x framecut-grabber-linux-amd64 && ./framecut-grabber-linux-amd64

3

Fill in the form and hit Grab

Paste the video URL, your Framecut server URL (e.g. https://your-framecut.example), and your API key — grab it from your server's /setup page (the app links straight to it). The server and key are remembered, so you only type them once. Age-restricted video? open Advanced options and pick a browser to pull cookies from.

4

Watch it land

Progress streams in the window. When it finishes, click Open in Framecut → to jump straight to your video, drag out a frame range, and render your GIF. Done.

Advanced options

Save toWhere kept files land with Local only (defaults to ~/Downloads/Framecut).
Local onlySkip the upload; keep the mp4 + subtitles so you can upload through the site's /add page instead.
Cookies fromPull cookies from a browser (chrome, firefox, safari, …) for age-restricted or sign-in-gated videos.
Frames / secHow many frames to extract per second (default 1).
JPEG qualityFrame quality 0–100 (default 85).
Max heightCap frame height in pixels (default 480); smaller videos are kept as-is.

Prefer the command line? Every download is also a CLI — run it with a video URL and --server / --api-key flags for the original scripted behavior.
